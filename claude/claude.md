# Discord 봇 제작
## 1. 개요
- 디스코드에서 동작하는 봇 제작
- 특정 위치의 날씨를 지정한 시간에 자동으로 알려준다.
- 알려주는 내용은 아래와 같다.
    - 오늘의 날씨 요약
    - 일별 : 최저기온, 최고기온, 평균습도, 미세먼지 농도, 오전 날씨, 오후 날씨
- 추가로 요청할 수 있는 정보는 아래와 같다.
    - 주간날씨 요약
    - 다른 도시의 날씨 묻기

## 2. 작업 방식
- `bash command` 실행 시 어떤 근거로 실행하는건지 한국어로 명시
- 바로 코딩하지 않고 어떤 작업을 할 지 순서를 먼저 제시

## 3. 테스트 및 실행과정
- 로컬 환경에서 실행하는 경우 정상 실행 중 오류가 발생하는 경우에만 보고하고, 그 외에는 정상 실행될때까지 별도로 물어보지 않고 진행한다.

## 4. git 규칙
- `[add]`, `[update]` 접두사와 진행한 내용 요약해서 코멘트 작성
- push까지 진행
