# 현행요약
- 히스토리는 모두 `히스토리.md`에 저장하고, 이 페이지에는 `현재의 최종 결정된 사항`만 기록한다. 
- 기능별로 기록한다.

## 언어/프레임워크
- Kotlin + JDA

## 날씨/미세먼지 데이터 소스
- 기상청+에어코리아, OpenWeatherMap 둘 다 지원 (사용자가 설정 시 선택)

## 저장소
- SQLite + Exposed ORM

## 스케줄러
- 앱 내부 코루틴 기반 스케줄러

## 인프라
- 저가 VPS/클라우드에서 Docker로 상시 구동

## 개발 환경
- IntelliJ IDEA
