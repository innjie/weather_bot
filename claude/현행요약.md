# 현행요약
- 히스토리는 모두 `히스토리.md`에 저장하고, 이 페이지에는 `현재의 최종 결정된 사항`만 기록한다. 
- 기능별로 기록한다.

## 언어/프레임워크
- Kotlin + JDA

## 날씨/미세먼지 데이터 소스
- 기상청+에어코리아, OpenWeatherMap 둘 다 지원 (사용자가 설정 시 선택)

## 저장소
- SQLite + Exposed ORM

## 스케줄러
- 앱 내부 코루틴 기반 스케줄러

## 빌드 도구
- Gradle(Kotlin DSL) + Gradle Wrapper 8.14.5
- Kotlin 2.2.0, Shadow(fat jar) 8.3.6

## 주요 의존성 버전
- JDA 5.6.1
- kotlinx-coroutines-core 1.10.2
- Exposed 0.61.0 (exposed-core/dao/jdbc/java-time)
- sqlite-jdbc 3.49.1.0
- kotlinx-serialization-json 1.9.0
- logback-classic 1.5.18
- dotenv-kotlin 6.5.1

## 패키지 구조
- 루트 패키지: `com.weatherbot`
- 현재: `config`(환경변수 로딩), `weather`(`WeatherProvider` 인터페이스, `WeatherProviderFactory`, `WeatherMessageFormatter`), `weather.kma`(기상청+에어코리아 구현체), `weather.owm`(OpenWeatherMap 구현체), `db`(`GuildConfigTable`, `DatabaseFactory`, `GuildConfigRepository`), `bot`(`CommandListener`, `BotScope`), `bot.commands`(`SlashCommand`, `WeatherConfigCommand`, `TodayWeatherCommand`, `OtherCityWeatherCommand`)
- 추가 예정: `scheduler`
