## 2. DB
### guild_configs
- 길드(서버)별 날씨 알림 설정 1건을 저장 (`guild_id` unique)

| 컬럼 | 타입 | 설명 |
|---|---|---|
| id | Long (PK, autoincrement) | |
| guild_id | Long, unique | Discord 길드 ID |
| channel_id | Long | 알림 보낼 채널 ID |
| location | Varchar(100) | 날씨 조회 지역명 |
| weather_provider | Varchar(20) | `KMA` 또는 `OWM` |
| notify_hour | Int | 알림 발송 시(0~23) |
| notify_minute | Int | 알림 발송 분(0~59) |
| created_at / updated_at | Instant | 감사용 타임스탬프 |

정의 위치: `src/main/kotlin/com/weatherbot/db/GuildConfigTable.kt`

### 지역-격자좌표 매핑 (기상청)
- `src/main/resources/kma_grid.json`: 지역명 → 기상청 격자좌표(nx, ny) + 시도명
- 코드와 분리된 리소스 파일로 관리하여, 지역 추가/좌표 변경 시 코드 수정 없이 파일만 수정하면 됨 (재빌드 필요)
- 현재는 주요 도시 18곳만 등록. 목록에 없는 지역은 명확한 에러 메시지로 안내
